How these numbers are built. Every assistant turn in the Claude Code transcripts is read, deduplicated on message id (forks and resumes copy turns into new files), then priced at published API rates per model and token kind. Calibration scales each window so it matches the percentage the Usage tab reported, which turns "share of my usage" into "share of that limit." Percentages are estimates; the ring colors track burn rate against the window's remaining time, not raw fill.
